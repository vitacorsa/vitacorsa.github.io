Versions

Every version, every change.

All releases of Vita Corsa with their changes, downloads and SHA-256 checksums. Compare a checksum before you run the setup.

  1. 0.2.0

    3 November 2026 Current 80 downloads on GitHub Download ZIP, 7.3 MB (version 0.2.0)
    • Career: qualifying that counts, a field that follows your pace, rivals with a memory, a real season finale with match point, a regular cast of 112 fictional drivers, 12 teams with team standings and team-mates, race formats (reversed grid, success ballast, evening and dusk races), a season sponsor and 36 sponsor brands, 20 invitations, three new cups, trophies and title scenes, circuit signs and a career start screen.
    • Interface: lap times on the result page, grid by pace in the race preparation, manufacturer logos shown from the game, clearer reasons on team cars, calm transitions (in VR everything only fades).
    • If a game update no longer fits Vita Corsa, Windows now tells you so with a short notification, and the game starts without Vita Corsa as before. If only the licence tests no longer fit, the rest of the career keeps running and only the licence tests are switched off until an update.
    • While Vita Corsa adapts to a new game version (more than 2 seconds), a notification says so. A failed adaptation is not repeated at every start.
    • Setup: clearer error messages with the next step and the help address (https://vitacorsa.github.io), a warning before an older setup replaces a newer version, the moved game folder is detected on update.
    • Uninstall: works even if an antivirus removed the starter; the remaining files are listed with their path. The "Remove Steam link" window now fits its text.
    • New sections in README.txt: "Antivirus and SmartScreen" and "The game does not start any more".
    • Runs alongside ACE UI App Loader: Vita Corsa now loads before other UI mods, and the setup no longer stops with code 13.
    • Licence tests: an attempt only counts from a standing start at the lights; every attempt of a session is kept for your best time.
    • Saves: if the game cannot deliver its storage, Vita Corsa shows "Try again" instead of empty slots and never overwrites a career it could not read.

  2. 0.1.0

    30 October 2026 54 downloads on GitHub Download ZIP, 7.2 MB (version 0.1.0)
    • First public version as a Windows setup: per-user installation without administrator rights, listed under "Installed apps".
    • The mod package is built and verified from your own game installation during setup; the starter rebuilds it by itself after game updates.
    • Guided Steam setup with a copy button; guided removal when uninstalling. Steam files are never changed automatically.
    • Way out: hold Shift when starting through Steam = this one time without Vita Corsa; the next normal start brings Vita Corsa back.
    • Updates by running the new setup: careers, extra content and other mods are kept; outdated own files are removed selectively.
    • Content: career with licence path (B, A, International, Pro) and licence tests, cups, dealers, garage, sponsors, invitations, free career, extra content (ZUSATZINHALTE.md, German) and installed mod cars at the dealer, in matching cups and as AI opponents (both optional, off by default).
    • "Schnitt" interface: car stage in the showroom (Home, Garage, Dealer, Workshop, invitations) with a photo stage as fallback; boards for Racing, cups, race preparation, licences, career path, driver record and settings; dedicated moments for titles, race results, licence tests and new licences; one icon family (Tabler Icons, MIT). Controller, keyboard, mouse.
    • Own menu tile with the Vita Corsa signet; brands appear by name, without manufacturer logos; own terms (VITA-CORSA-TERMS.txt).
