Made for the wheel

Your wheel is enough.

Most of us race in a rig, so every main path works with up, down, left, right, confirm and back. Pad, keyboard and mouse work everywhere too, with shortcuts for those who have them.

  • Button hints follow the device you are using.
  • Nothing is left out because a wheel cannot do it. Search and names simply use the keyboard.
  • Moving through a menu never waits for an animation.

Controls

Controls that explain themselves.

Setting up a wheel is often the hardest part of a sim. The new controls page takes you through it and shows what every button does.

  • Setup assistant for each device, step by step.
  • Button finder: press any button on your wheel and see what it is bound to. Many wheels only show numbers.
  • Input monitor: every axis and button, live.
  • The response of each axis as a curve.
  • Warnings for double bindings and for bindings you still need.
  • Control profiles right on the same page.

On every screen

From 16:9 to 32:9, in six languages.

Every screen is checked on normal, wide and super wide monitors. Menus use the game's own words in all six of its languages, so nothing reads like a mod.

  • English, German, Italian, French, Spanish and Chinese.
  • Each part can be switched on or off on its own.
  • If a part runs into a problem, the game's own screen takes over.

For modders

Open for parts of your own.

The new interface is built from parts, and other modders will be able to add their own. A template and a checker help you test a part before you share it.

A new interface for the whole game

Vita Corsa could give the whole game a cleaner, faster interface, not just the career: main menu, car selection, quick race and more, easy to use with pad, keyboard and mouse and on every screen from 16:9 to 32:9. Each part could be switched on or off on its own.

The whole roadmap

Good to know.

Do I need Vita Corsa for it?

No. Vita Corsa UI is meant to run without the career, as a download of its own. Until then it comes as part of Vita Corsa, and you can switch off every part you do not want.

Can I install both?

Install only one of them. Vita Corsa already contains the whole new interface, so you never need both.

Does it work with my wheel?

The wheel comes first. Every main path works with up, down, left, right, confirm and back, as set in the game's own controls. Being checked: we test on our own rig, and reports from players with other wheels help a lot.

What happens when the game updates?

Being checked: each part knows the game version it was made for. If something no longer fits after an update, that part hands back to the game's own screen until a new version follows.

Does it work with other UI mods?

Mods that replace the game's menu pages may conflict with it, the same as with Vita Corsa today. Being checked: how it fits next to other UI mods.
